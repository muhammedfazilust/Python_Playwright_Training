# Python Milestone Assessment

This repository contains solutions for the Python Milestone Assessment.

## Contents
- **question1/**: Student Marks Management System
- **question2/**: Simple Employee File Management


## How to Run
Run each question from its own folder:
```bash
cd question1
python main.py

cd ../question2
python main.py
```

## Submission Notes
Each folder contains its own `README.md` with the problem statement, approach, run instructions, sample input and output, and the Python concepts used.
